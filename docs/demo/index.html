Plants screened together (WSCR, CSCR and SCRIF)

Each bus in a group gets a plant of the size above. WSCR = Σ(SCMVAᵢ × Pᵢ) ÷ (ΣPᵢ)², assuming the plants are fully interacting (electrically close); for buses far apart this is conservative. CSCR ties the group's points of interconnection together; SCRIF uses the network's interaction factors, so it sits between each plant's SCR and the WSCR. The group's flag and the Flagged count use WSCR, the most conservative.

Method and assumptions

  • Short-circuit MVA source: network model (ieee39_assumed.json), classical flat-start (1.0 pu). SCMVA excludes the contribution of inverter-based resources, per NERC.
  • SCR = SCMVA ÷ plant rating (MW). WSCR = Σ(SCMVAᵢ × Pᵢ) ÷ (ΣPᵢ)², assuming the plants in a group are fully interacting.
  • Flag bands: below 2 very weak; 2 to below 3 weak; 3 or above no flag. Default bands follow HVDC planning practice (IEEE Std 1204-1997); user-configurable.
  • Bus scan: a hypothetical 1500 MW plant was screened at each bus, one at a time. Buses listed in the groups file were also screened together with WSCR, each with a plant of the same size; WSCR assumes the plants in a group are fully interacting, so group only buses that are electrically close.
  • Bus labels are the bus names in the network file. The Model index column is each bus's position in the file, counting from 0 (so Bus 30 can be index 29).
  • Nominal ratio: 11 transformer(s) have a tap position away from neutral or a rated turns ratio different from the bus voltage ratio; the classical method uses the nominal ratio, so these are not modeled. This is the usual flat-start assumption; it can change the short-circuit MVA by several percent at buses next to those transformers.
  • SCRIF_i = SCMVA_i ÷ (P_i + Σ IF_ij·P_j), with interaction factors IF_ij = |Z_ij ÷ Z_jj| from the classical network impedance matrix (NERC Reliability Guideline, 2017). CSCR = short-circuit MVA with the group's POIs tied together ÷ total MW; NERC's definition ties the plants' medium-voltage buses, which are not in a transmission model, and divides by the plants' nominal MVA ratings (use --basis MVA to match).
  • N-1: each of 55 line circuits, transformer units and generator units was removed in turn (classical method); the lowest short-circuit MVA at each bus and the outage causing it are shown.
  • EMT triage: NERC (2024, Chapter 1): if any one of the listed situations applies, EMT studies should be considered. NERC (2024, Chapter 1): “having a high level of system strength alone should not rule out the need for EMT studies.” Priorities order the work; they are SCR-Screen's judgment, not NERC's. NERC lists the situations without ranking them. Priority 1: any strength metric below the very-weak threshold in any condition; series compensation, FACTS or HVdc nearby; a system event that positive-sequence models cannot reproduce; or the lowest SCR below the OEM minimum SCR. Priority 2: any strength metric below the weak threshold; other IBRs nearby; or any other situation answered yes. Priority 3: no screening trigger found. In a scan, the conditions are the intact network and the worst single outage.
  • EMT triage, nearby: an existing IBR or device is nearby when max(IF_ij, IF_ji) with the bus is at least 0.5 (--ibr-threshold; SCR-Screen's default judgment value). Series compensation is found as lines with negative series reactance, FACTS as svc/ssc/tcsc and HVdc as vsc/dcline elements. A negative reactance can also be an equivalent branch of a reduced model; answering series_compensation = no in the POI information file tells the triage it is not a series capacitor.
  • EMT triage: no POI information file (--poi-info) was given, so the situations a network model cannot show (e.g. pre-existing oscillation, RAS, system events) are not checked. For a full data sheet per POI, use: scr-screen triage.
References: NERC Reliability Guideline, Integrating Inverter-Based Resources into Low Short Circuit Strength Systems (2017); NERC White Paper, Short-Circuit Modeling and System Strength (2018).

About the live inputs

Change any value to recalculate instantly in your browser (per-bus distances and POI costs are editable in the cost table). SCR = SCMVA ÷ plant MW; short-circuit MVA does not change with these inputs. Files exported with --out keep the values the report was created with (1500 MW).
Screening only. SCR-Screen provides screening-level indicators of system strength. Results do not replace interconnection studies, detailed positive-sequence or EMT analysis, or the requirements of the applicable transmission provider. Thresholds are user-configurable and have no universal validity. SCR-based metrics assume grid-following inverters and do not replace the inverter manufacturer's minimum SCR rating.
