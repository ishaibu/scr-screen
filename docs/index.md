# SCR-Screen

Open-source short-circuit ratio (SCR) screening for solar, wind, and battery storage interconnection.

- **[SCR-Screen Lite](lite/)**: browser calculator; nothing to install, nothing sent anywhere.
- **[Interactive demo](demo/)**: IEEE 39-bus scan with assumed data and illustrative costs, as a dashboard. The same scan as a [one-page report](demo/report/).
- **[Design specification](design-spec)** and **[verification record](verification)**
- **[Source code, installation, and documentation](https://github.com/ishaibu/scr-screen)**: `pip install scr-screen`

Screening only: results do not replace interconnection studies.
